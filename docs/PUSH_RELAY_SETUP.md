# 「◯◯が撮った」通知の送り役を置く（Google Apps Script・無料）

今日の担当が撮ったら、ほかのメンバーに「◯◯が今日の1枚を撮りました」を届ける。
送り役は **Google Apps Script（GAS）のウェブアプリ**。Google アカウントだけで無料で動き、カードの登録も要らない
（Firebase の Cloud Functions は従量課金でないと動かせないので、その代わり。2026-10-15）。

かかる時間はおよそ20分。全部やっても、どこで止めても、ほかの機能には影響しない
（送り役の URL を入れるまで、アプリは「撮った」を知らせないだけ）。

## しくみ

```
撮った人の iPhone ──「今日の1枚を撮った」──▶ 送り役（GAS） ──▶ Firebase Cloud Messaging（無料） ──▶ ほかの人の iPhone
                    （匿名ログインの身分証つき）   │
                                                  └─ Firestore を読んで「本当にこの人が今日撮ったか」を確かめる
```

- 送り役の URL を誰かに知られても、勝手に通知を飛ばすことはできない（身分証が本物で、本当にその人が今日その枠を撮ったときだけ送る）。
- 1つの枠につき1回だけ送る（撮り直しや、同期のたびには送らない）。
- 届くのは、新しい版のアプリを入れて、通知を許可した人だけ。

## 前提

- [`FIREBASE_SETUP.md`](FIREBASE_SETUP.md) の **1（匿名ログイン）** と **2（ルール）** が済んでいること。
- 同じく **4 の APNs キーのアップロード**が済んでいること（Apple の通知の鍵を Firebase に預ける。無料）。

## 1. サービスアカウントの鍵を作る

送り役が Firestore を読んで通知を送るための「合鍵」。

1. Firebase コンソール → ⚙ プロジェクトの設定 → **サービス アカウント** タブ
2. 「Firebase Admin SDK」のところで **新しい秘密鍵を生成** → `.json` ファイルがダウンロードされる

> **この JSON は Rotash のサーバーの合鍵そのもの。** アプリにも GitHub にも LINE にも絶対に入れない。
> 入れる場所は、次の GAS の「スクリプト プロパティ」だけ。もし漏れたら、同じ画面で鍵を削除して作り直す。

## 2. GAS を作る

1. [script.google.com](https://script.google.com/) → **新しいプロジェクト**。名前は「Rotash push relay」など
2. 最初からある `コード.gs` の中身を全部消して、このリポジトリの **`tools/push-relay.gs` の中身をまるごと貼り付け** → 保存
3. 左の ⚙ **プロジェクトの設定** → 下の **スクリプト プロパティ** → 「スクリプト プロパティを追加」で2つ入れる

   | プロパティ | 値 |
   |---|---|
   | `SERVICE_ACCOUNT_JSON` | 1 でダウンロードした JSON ファイルの中身を**まるごと**（`{` から `}` まで） |
   | `FIREBASE_API_KEY` | `Rotash/Services/Sync/SyncConfig.swift` の `firebaseAPIKey` と同じ値 |

4. エディタに戻り、上の関数の選択で **`checkSetup`** を選んで ▶ **実行**
   - 初回は「承認が必要です」と出るので、自分の Google アカウントで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全でないページ）に移動」。自分で作ったスクリプトなので問題ない）
   - 下の実行ログに `OK: rotash-f83a4` と出れば、鍵は正しく入っている

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ** → 種類の ⚙ で **ウェブアプリ**
2. 設定:
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
3. **デプロイ** → 出てくる **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー
4. ブラウザでその URL を開くと `{"ok":true,"service":"rotash-push-relay"}` と出る（動いている印）

## 4. アプリに URL を入れる

`Rotash/Services/Sync/SyncConfig.swift` の

```swift
static let pushRelayURL = ""
```

に、3 でコピーした URL を入れてビルドする。

## 5. 確かめる

2台の iPhone（どちらも新しい版で、通知を許可している）で、今日の担当の方が撮る。
数秒〜十数秒で、もう片方に「◯◯ が今日の1枚を撮りました」が届けば完成。

届かないとき:

- GAS の左の **実行数** を開くと、呼ばれたか・エラーが出たかが見られる
- `unauthorized` … 匿名ログインが有効になっていない（`FIREBASE_SETUP.md` 1）
- `nothing to send` … 撮った人とほかの人の両方が新しい版で、一度アプリを開いているか（uid がグループに載るのは、新しい版で同期したとき）
- FCM のエラー … APNs キーのアップロード（`FIREBASE_SETUP.md` 4）を確かめる

## グループのメッセージの通知（2026-10-19）

同じ送り役が、グループのメッセージの通知（「AKI: 今日の空きれい」）も送る。アプリはメッセージを送って同期したあとに
`{ idToken, inviteCode, kind: "message", messageID }` を送ってくる。送り役は、そのメッセージが本当にグループの状態に載っていて、
送ったのがその人かを確かめてから、ほかのメンバーへ送る（送ってから30分を過ぎたものは送らない。同じメッセージでは1回だけ）。

**`tools/push-relay.gs` を 2026-10-19 版に貼り替えて、下の「コードを直したとき」の手順で新バージョンにすること。**
貼り替えないと、メッセージの通知だけが届かない（「撮った」の通知は今までどおり）。

## コードを直したとき

`tools/push-relay.gs` を変えたら、GAS に貼り直して、**デプロイ → デプロイを管理 → ✏ → バージョン「新バージョン」→ デプロイ**。
こうすると URL は変わらない（「新しいデプロイ」を作ると URL が変わるので、アプリも直すことになる）。

## 無料の範囲

GAS の無料枠（1日に外へ通信できる回数など）は、友達グループの規模なら十分に収まる。
1枚撮るごとに、送り役の通信は「人数 + 4回」ほど。
