## 0. いまの考え（2026-10-17 オーナーの整理）

### 核と手段

- **核（いちばん大事なもの）は、7分割のレイアウト。** 「まだ見たことないけど、結構いいんじゃね？」と感じたもの。7分割を活かすには「7日で7枚」がちょうどいい
- **ほかの機能・制約・やらないこと（NEVER）は、核をヒットさせるための手段。** BeReal・Setlog など最近流行ったアプリをオーナーなりに分析して入れたもの（自由すぎるのは良くない／ユーザーにある程度の強制力が要る／ストーリーなど広げる先に合わせる、など）。目的そのものではないので、変えてよい
- **本当の願い: あのレイアウトを使って、流行るアプリを作りたい**

### 制約を決めるときの基準

> **そのルールは、7分割の作品を、より良く・より見せたくなるものにするか？**

例: 「1日1人」は7枠に7人の視点が並ぶので作品が面白くなる可能性がある。1人で7枚だと1人の目線になり、Setlog に近づく。

### ありえる方向（まだ決めない）

- 7日で1つの作品にして、**1日1回開くことに価値を持たせる**（下の 1〜4 章）
- 朝と夜に撮りたいものがあれば両方残す、など**撮り方を広げる**
- どちらが「BeReal の2分ルール」型（独自のルールを足す→アイデンティティになる）で、どちらが「トーク機能を無くす」型（欠かせないものを無くす→魅力が下がる）になるかは、まだ分からない

### 決め手：日曜にストーリーへ載せたときの反応

- 完成した作品を Instagram のストーリーに載せ、反応を見る。**反応が良くなければ、レイアウトが受けなかったと考えて、やめることもある**
- 「レイアウトが受けるか」と「アプリをやりたいか」は別の問いなので、分けて見る

| | 「やりたい」「これ何？」と聞かれた | 聞かれなかった |
|---|---|---|
| **反応が良かった** | レイアウトもアプリも有望 → 続ける | レイアウトは良い、撮り方の仕組みが問題 → 仕組みを変えて試す |
| **反応が良くなかった** | 仕組みに興味を持たれた → 伝え方を変えて再挑戦 | レイアウトが響いていない → やめるのを考える |

- 判断の前に決めておくこと:
  - **比べる相手:** ふだんのストーリーの反応と比べる
  - **数えるもの:** いいねだけでなく、**返信・DM で「これ何？」と聞かれた数**（いちばん強いサイン）
  - **回数:** 1回で決めない。最初の作品は試しの写真や土日だけの短い週が混ざるので、できれば2〜3回
- 費用ゼロの追加テスト: アプリ無しで、写真7枚から手作業で7分割の画像を作ってストーリーに載せる（「1人で7枚」と「7人で7枚」の反応も比べられる）

補足: 友達B（「1人で7枚」を言った人）は部活の Setlog をグループで使ってハマっているので、**グループ形式そのものは問題の本質ではなさそう**。「1人にする」から先に着手しない。

継続の仕組みは4つに分けて考える:

| 軸 | 中身 | Rotash の今 |
|---|---|---|
| ① 行動するきっかけ | 通知、決まった時間、ホーム画面での表示 | 朝の「今日は ◯◯」、夜21時の1通、「◯◯が撮った」（送り役は未設置） |

- **仮説C: 完成までの過程に期待がない**（日曜の完成は魅力でも、月〜土の変化が楽しくない）

注意:

- 申し訳なさ・罪悪感で投稿を増やすやり方は、一時的には効いても長続きしにくい。撮れない日を責めるような空白の見せ方は、抜ける理由になる

## 3. 考え方の柱

### 柱 A：撮る側と見る側を、別の問題として考える

| | 撮る側（その日の担当） | 見る側（担当でない人） |
|---|---|---|
| どれくらいあるか | 1人あたり週に1〜2日 | 1人あたり週に5〜6日（こちらが大部分） |
| 困っていること | 撮ったら終わり。反応が返ってこない（見られたかも分からない） | 開いても新しい写真が1枚あるだけ。自分にできることが無い |
| 測る数字 | 担当日に撮った割合 | 担当でない日に開いた割合 |

見る側の小さな行動（たとえばワンタップの反応）は、そのまま撮る側への反応になる。1つの手で両方に効く可能性がある。ただし分析は分けておく。

### 柱 B：1日1回を価値にする（「回数」ではなく「1回の濃さ」）

問いを「どう回数を増やすか」から「1回開いたときの中身をどう濃くするか」に変える（エレベーターの鏡と同じ発想）。

- 成功例: **Wordle** はわざと1日1問。1回が楽しく、全員が同じ日に同じことをして、結果を見せ合える
- 注意: **BeReal** は1日1回の通知だけでは、物珍しさが消えたあとに中身が薄く感じられて大きく減った

材料の候補（**まだ作らない**。テストの結果を見て選ぶ）:

- みんな同じ時刻に公開する（今の「◯◯が撮った」をすぐ届ける通知とぶつかるので、どちらを取るか決める必要あり）
- 10秒で終わる決まった流れ（見る → 裏返す → ワンタップで反応 → 「あと◯枚で完成」 → 閉じる）
- 日曜の完成を週の山場にする
- 伝え方：「1日1回、10秒。SNS疲れしない友達アプリ」のように、回数の少なさを売りにする

気をつけること: 今のテスターは Setlog・BeReal を使っていて「もっとやることが欲しい」側の人たち。この方向が刺さる相手かどうかは、まだ分からない。
